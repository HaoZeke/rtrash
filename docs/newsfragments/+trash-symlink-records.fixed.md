A symlink planted as `directorysizes`, a `.trashinfo` record, or `.rtrash.lock` is not followed. The cache link is ignored and the size comes from a walk, a linked record is not an item, and the lock open fails instead of locking the file the link names. `trash-list` no longer prints an `[Errno N]` line for that record. `rtrash list` counts the name as not a trash record, and `status --check` reports `stray:`.
