`rtrash who` prints one line per holder of each path, with the user and the command line, and one line when nothing holds a path. That line says the result is partial when that path could not be checked in full or a process could not be inspected. `rtrash put` refuses a copy onto a trash on another device unless `--allow-cross-device` is given. With the flag, the copy is checked before the original is removed.
