`rtrash du --filter-from=FILE` reads rsync filter rules and leaves out what they exclude. The first rule that matches an entry decides, as in rsync, so a `+` line keeps an entry from the `-` lines below it. A leading `/` anchors a pattern at PATH, a pattern with another `/` matches the end of the path, and `dir/***` takes the whole folder. A merge rule or a rule with modifiers is refused with its line number. The flag takes no `-f` snapshot and no `--devices` list.
