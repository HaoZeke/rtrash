Add an optional `rtrash-hud` program that prints the trash item count and reclaimable size, the same numbers as `rtrash status`. The display does not take the trash lock or rewrite `directorysizes`, and it has no age or size filter (`--older-than`, `--newer-than`, `--larger-than` and `--smaller-than` are unrecognized options and the program exits 2). It is a workspace member and is not built with the CLI or shipped in the musl tarball. A desktop launcher is `crates/rtrash-hud/rtrash-hud.desktop`.
