`rtrash du --min-size=SIZE` now works outside `--dupes`, as `dust --min-size` does: the table and `--json` of a scan drop every row below that size. The floor measures disk use, or the apparent size under `--apparent`. A row of exactly that size stays, the totals still count everything, and `-n` still caps each list. For now `--tree`, `-i`, `--pick`, `--print0`, `-f`, `-o`, `--stacks`, `--ncdu`, `--types`, `--devices` and the `items` and `mtime` sort keys refuse it with exit status 2.
