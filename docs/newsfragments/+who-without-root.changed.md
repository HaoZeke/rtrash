`rtrash who` now says on stderr, in JSON mode too, how many processes it could not inspect, and that a path may still be in use when it saw no holder. `rtrash put --in-use=refuse` (and `rm`, which runs put) no longer takes an uninspected process for no process: without root it refuses an item no visible process holds, naming the count, unless `-f` is given, which trashes it with a warning. The same holds when the platform lists no holders and, on Windows, when the Restart Manager could not check a path in full. `--in-use=warn`, the default, is unchanged.
