Tests no longer reach the Windows Recycle Bin. `common::rtrash(home)` now points debug builds at a scratch bin under `home` through `RTRASH_TEST_BIN_DIR`: a put moves the item there as a `$R` file with its `$I` record, and the du trash summary counts that folder. Precheck fails when a test or one of those two places drops the scratch bin. Round 231 went red on Windows when a parallel `du --trash-dupes` filled the real bin that another test's summary read.
