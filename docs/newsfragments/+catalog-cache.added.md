List, status, undo, trash-stats, retention and the Python `list_trash` binding reuse a sealed per-root catalog of trash records while the trash is unchanged, and read every record again after a put, restore, rm, empty or an edit by another tool, including an edit that keeps the file's timestamps. A catalog is used only once every record is older than the blob by twice the coarse clock's tick, and at least 20 ms. Empty, a size budget and the check before an unscoped empty read each record again before they delete. `RTRASH_NO_CACHE` set to `1`, `true` or `yes`, in any case, reads every record and does not delete the catalog. Any other value leaves the catalog on. The macOS Finder list and the Windows Recycle Bin never use the catalog.
